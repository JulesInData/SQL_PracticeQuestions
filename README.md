### **Question 1: Rank Customers by Total Spending**

--- 

Using a **Common Table Expression (CTE)**, calculate the total amount spent by every customer on orders that were not cancelled.

### **Required Output**

Your query should display the following columns:

* Customer ID
* Customer name
* Number of orders
* Total amount spent
* Average order value
* Customer spending rank

### **Ranking Requirement**

Use a second CTE or a window function to rank customers from the highest spender to the lowest spender.

### **Question 2: Find the Best-Selling Product in Each Category**

--- 

Using a **Common Table Expression (CTE)**, calculate the total quantity sold and total revenue generated by every product.

Exclude all orders with a status of `Cancelled`.

### **Required Output**

Your query should display the following columns:

* Product ID
* Product name
* Product category
* Total quantity sold
* Total revenue generated
* Product rank within its category

### **Ranking Requirement**

Use a second CTE or a window function to rank products within each category from the highest-selling product to the lowest-selling product. Return only the best-selling product in each category.

### **Question 3: Count Orders by Status**

---

Using a **Common Table Expression (CTE)**, count the number of orders for each order status.

### **Required Output**

Your query should display:

* Order status
* Number of orders

Sort the results from the status with the highest number of orders to the lowest.

### **Question 4: Find Customers with Orders**

----

Using a **Common Table Expression (CTE)**, display customers who have placed at least one order.

### **Required Output**

Your query should display:

* Customer ID
* Customer name
* Number of orders

Sort the results from the customer with the highest number of orders to the lowest.

### **Question 5: Get Customer Orders Using a Stored Procedure**
--- 

Create a stored procedure named `GetCustomerOrders` that accepts a customer ID as a parameter and returns all orders placed by that customer.

### **Required Output**

The stored procedure should display:

* Customer ID
* Customer name
* Order ID
* Order date
* Total amount
* Order status

Sort the results from the most recent order to the oldest.

The stored procedure should also return a clear message when the customer does not exist or has not placed any orders.
